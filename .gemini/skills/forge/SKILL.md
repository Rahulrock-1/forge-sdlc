# Forge SDLC Skill

Use this skill when the user requests SDLC capabilities like architecture, specification, code review, planning, task breakdown, or security audits.

## Capabilities:
- `forge architecture`: BMAD C4 Architecture & System Design
- `forge specify`: Spec Kit Given-When-Then SDD (`spec.md`)
- `forge review`: BMAD Multi-Lens Review (`bmad-review`)
- `forge plan`: Spec Kit Technical Plan (`plan.md`)
- `forge tasks`: Spec Kit Atomic Task Breakdown (`tasks.md`)
- `forge security`: Forge Internal STRIDE & SAST Scan
- `forge converge`: Spec Kit Task Burndown & Convergence
